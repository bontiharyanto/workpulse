# ADR-0042 — Self-hosted map tiles (PMTiles on MinIO + MapLibre GL JS)

**Status:** Approved (design locked) — 2026-08-07
**Deciders:** Platform, HR Product, Ops
**Supersedes:** — (extends ADR-0040 map picker; replaces the OSM
raster + Nominatim direct-call posture from that ADR)
**Superseded by:** —

## Context

ADR-0040 shipped the geofence map picker on **Leaflet + OpenStreetMap
raster tiles + Nominatim direct-from-browser** for search. Two of
those choices are now liabilities:

1. **External availability + rate-limits.** `tile.openstreetmap.org`
   [enforces a 2-per-second per-IP tile cap and forbids "heavy use in
   commercial contexts"](https://operations.osmfoundation.org/policies/tiles/).
   A busy tenant's admin editing many geofences plus supervisors
   opening location-share detail pages plausibly trips that gate.
   Nominatim is even stricter (1 req/sec per IP), and their AUP
   [explicitly forbids using it as a production geocoder](https://operations.osmfoundation.org/policies/nominatim/).
2. **CSP surface.** ADR-0040 opened `img-src`
   `https://*.tile.openstreetmap.org` and `connect-src`
   `https://nominatim.openstreetmap.org`. Every additional external
   host is one more supply-chain risk (typosquat, hijack, malicious
   CDN response) that Workpulse doesn't need if the same content can
   be served same-origin.

Track 2 (ADR-0041) added `LocationShareRequest` detail pages that
today link OUT to `openstreetmap.org` for viewing coordinates —
awkward for HR + supervisors reviewing sensitive coord data in an
enterprise console. We want an inline preview map here too, using the
same tile stack.

A tertiary motivation: some Workpulse tenants operate in fully
air-gapped or VPN-only environments where `tile.openstreetmap.org` is
not reachable at all. Those tenants can't use ADR-0040 today.

## Decision

Serve **vector map tiles from our own infrastructure** via three
API endpoints — `/maps/style.json`, `/maps/tiles/{z}/{x}/{y}.mvt`,
`/maps/glyphs/{fontstack}/{range}.pbf`, `/maps/sprites/*` — backed by
a single **PMTiles archive** stored in a new MinIO bucket
`workpulse-maptiles`. Replace **Leaflet** with **MapLibre GL JS**
(via `react-map-gl` v8) on the frontend. Proxy **Nominatim** through
a new `/maps/geocode` endpoint with server-side rate-limit + short-TTL
in-memory cache; the FE no longer contacts `nominatim.openstreetmap.org`
directly.

### 1. Backend — read-through cache

Nest module `apps/api/src/maps/` (module + controller + service + one
domain helper).

**Endpoints (all public, no auth — tiles do not carry tenant data):**

| Method | Path                                | Response                        | Cache header                                  |
| ------ | ----------------------------------- | ------------------------------- | --------------------------------------------- |
| `GET`  | `/maps/style.json`                  | `application/json` (Style Spec) | `public, max-age=300`                         |
| `GET`  | `/maps/tiles/{z}/{x}/{y}.mvt`       | `application/vnd.mapbox-vector-tile` | `public, max-age=604800, immutable`      |
| `GET`  | `/maps/glyphs/{fontstack}/{range}.pbf` | `application/x-protobuf`     | `public, max-age=2592000, immutable`          |
| `GET`  | `/maps/sprites/{name}.{png,json}`   | `image/png` / `application/json` | `public, max-age=2592000, immutable`         |

The tile endpoint does **PMTiles byte-range fetching from MinIO**:

```ts
// Deterministic: PMTiles archive header encodes the byte range for
// every (z, x, y) tuple. We compute the range client-side (in the
// Nest service) using the `pmtiles` npm library, then issue a
// single `GetObjectCommand` with a `Range: bytes=offset-end` header
// against MinIO. No local file cache — MinIO already caches; adding
// a second cache layer creates invalidation bugs when the ops team
// swaps the archive.
```

The style JSON is generated by the service on-the-fly (< 5 KB, cheap)
so tile / glyph / sprite URLs point at the API's own origin. That
keeps every downstream URL under our control (no rewriting on the FE).

**Auth / rate-limit posture.**

- Tiles + glyphs + sprites: unauthenticated, cache-key by URL only.
  A tile has no PII. Anyone with the URL sees the same MVT bytes.
- Style JSON: unauthenticated (same reasoning).
- **`/maps/geocode`: authenticated** (`JwtAuthGuard`). Address lookups
  can hint at where a user lives / works, and Nominatim's AUP requires
  attribution + best-effort abuse containment. Auth gate lets us log
  the caller and enforce per-user quotas.

### 2. Storage — new MinIO bucket

**Bucket:** `workpulse-maptiles` (new), separate from `workpulse`
(attachments). Rationale: different retention story (map tiles are
static reference data, not user content), different access story
(read-through by API only, no presigned URLs to clients), and it lets
the ops team wipe/rehydrate the map bucket without touching
attachments.

**Contents:**

```
workpulse-maptiles/
├── indonesia.pmtiles              # ~450 MB, from Protomaps daily
├── glyphs/
│   ├── Noto Sans Regular/         # PBF glyphs per fontstack
│   │   ├── 0-255.pbf
│   │   ├── 256-511.pbf
│   │   └── ...
│   └── Noto Sans Bold/
│       └── ...
├── sprites/
│   ├── default@1x.png
│   ├── default@1x.json
│   ├── default@2x.png
│   └── default@2x.json
└── style/                         # Optional pre-built style JSONs
    └── liberty.json               # Reference; service usually renders
                                   # its own so it can rewrite URLs
```

MinIO bucket policy: **private, no public read**. API reads via IAM
credentials the same way it reads attachments today.

### 3. Bootstrap — manual ops procedure (documented)

Downloading a ~450 MB file every deploy is not appropriate for CI. Ops
runs a documented one-shot procedure to seed the bucket, then re-runs
it monthly (or when a Protomaps release adds a feature we want).

Full procedure lives at [`docs/OPS/MAP-BOOTSTRAP.md`](../OPS/MAP-BOOTSTRAP.md).
Short version:

```bash
# 1. Download Protomaps daily build (Indonesia extract).
curl -L -o /tmp/indonesia.pmtiles \
  https://build.protomaps.com/{DATE}-indonesia.pmtiles

# 2. Upload to MinIO via `mc`.
mc alias set workpulse http://minio:9000 workpulse workpulse-secret
mc cp /tmp/indonesia.pmtiles workpulse/workpulse-maptiles/indonesia.pmtiles

# 3. Copy glyphs + sprites (one-time, changes rarely).
mc mirror ./maplibre-glyphs workpulse/workpulse-maptiles/glyphs
mc cp ./sprites/default@1x.{png,json} workpulse/workpulse-maptiles/sprites/
mc cp ./sprites/default@2x.{png,json} workpulse/workpulse-maptiles/sprites/
```

CI does NOT run this. Fresh dev environments (`docker compose up`)
start with an **empty** map bucket — the frontend renders a "map
tiles unavailable, contact ops" placeholder. This is a **deliberate
choice**: adding a 450 MB download to `docker compose up` would break
onboarding for anyone with a slow connection.

The ops runbook includes verification (`mc stat`, first-byte fetch)
and a rollback (`mc cp` the previous archive back).

### 4. Frontend — MapLibre GL JS

Drop `react-leaflet` + `leaflet` (~150 KB gz). Add `maplibre-gl`
(~120 KB gz) + `react-map-gl` v8 (~15 KB gz) + `@turf/circle` (~8 KB
gz, for drawing the geofence radius as a GeoJSON polygon since
MapLibre has no built-in circle-in-meters primitive).

**Migration mechanics:**

- `apps/web/components/features/admin/geofences/geofence-map-picker.tsx` — rewritten to `<Map>` +
  `<Source>` + `<Layer>` primitives. Same public props (`value`,
  `onChange`, `heightPx`, `showControls`).
- Marker: MapLibre `Marker` component, draggable.
- Geofence circle: precomputed GeoJSON polygon via `turf.circle`
  with 64 segments (visually smooth, cheap).
- Address search: same UX, but `fetch('/api/v1/maps/geocode?q=...')`
  instead of `fetch('https://nominatim.openstreetmap.org/search?...')`.
- "Use my location" and click-to-place: unchanged (pure browser
  Geolocation + MapLibre `click` event).

**Supervisor location-share detail** — gets a small inline map
preview at 240 px tall (roughly Google-Maps card size) with a single
marker at the ping's coord, using the same map component with
`showControls={false}`. Removes the "Open in OpenStreetMap" external
link.

### 5. CSP tightening

Middleware (`apps/web/middleware.ts`) loses two entries:

- **Removed:** `img-src` `https://*.tile.openstreetmap.org`
- **Removed:** `connect-src` `https://nominatim.openstreetmap.org`

All map traffic goes to `NEXT_PUBLIC_API_URL` (already in
`connect-src`). Tile PNGs are gone — MVT is fetched via
`fetch()`, so they land in `connect-src`, not `img-src`. Sprite PNGs
are same-origin (via the API), so `img-src 'self'` suffices without a
new host.

### 6. Env vars (added)

```
# apps/api
MAPS_ENABLED=true                          # kill switch (false = 503)
MAPS_TILES_BUCKET=workpulse-maptiles
MAPS_PMTILES_KEY=indonesia.pmtiles
MAPS_GLYPHS_PREFIX=glyphs/
MAPS_SPRITES_PREFIX=sprites/
MAPS_GEOCODE_UPSTREAM=https://nominatim.openstreetmap.org
MAPS_GEOCODE_USER_AGENT="Workpulse/1.0 (ops@example.com)"
MAPS_GEOCODE_QPS=1                         # matches Nominatim AUP
MAPS_GEOCODE_CACHE_TTL_S=86400             # 24h in-memory cache
```

All defaults chosen to match Nominatim's Acceptable Use Policy — we
identify ourselves in the `User-Agent`, keep to 1 QPS, cache
aggressively.

## Consequences

### Positive

- **No external map dependency.** Air-gapped tenants work. `tile.openstreetmap.org`
  outages don't cause the geofence editor to appear broken.
- **CSP simpler.** Two hosts removed from `img-src` + `connect-src`.
- **MVT vs PNG.** Vector tiles are ~3–5× smaller on the wire than
  raster; MapLibre also crisps them at any zoom without pixelation.
  Users on cheap mid-range Android phones benefit most.
- **Predictable cost.** Reads from MinIO are free; the PMTiles archive
  is a one-time ~450 MB storage cost. No per-request tile fees.
- **Inline previews on sensitive pages.** Supervisor detail no longer
  sends coords to `openstreetmap.org` when the HR viewer opens the
  card.

### Negative

- **Ops runbook required.** Fresh installs need a manual step. Doc
  is prominent in `docs/OPS/MAP-BOOTSTRAP.md` and `docs/README.md`.
- **Extra 450 MB of MinIO storage.** Trivial in most deployments; a
  concern on shared free-tier infra where minio_data has a small
  volume. Ops adjusts volume size once at provisioning.
- **PMTiles library dependency (server-side).** `pmtiles@^3` npm
  package (~50 KB, MIT). Small blast radius but one more transitive
  dep to track in `pnpm audit`.
- **MapLibre bundle size ~ same as Leaflet.** No win on JS payload;
  the win is on tile bytes + external-dep removal.
- **Nominatim still runs on their servers.** We only *proxy* it; if
  their upstream goes down, geocoding still fails. Follow-up work
  could add a fallback to a paid geocoder (Mapbox / Google) behind an
  env flag — deferred.
- **`/maps/geocode` becomes a shared resource.** A single tenant that
  hammers the geocoder can saturate the per-instance QPS budget. We
  guard with per-user token-bucket at 1 req / 2 sec (server-side).

## Alternatives considered

| Option | Rejected because |
|---|---|
| **Keep OSM raster tiles as-is** | Solves nothing — the whole point is to remove external deps and CSP surface. |
| **Self-hosted TileServer GL (docker container)** | Heavier than PMTiles (needs a running Go process + persistent volume with vector tiles). PMTiles is a single file we can serve with our existing Node stack. |
| **Mapbox GL / Google Maps** | Both require paid API keys per tenant + CSP allowlist for their CDNs. Runs counter to the "reduce external deps" goal. |
| **Presigned URLs direct from browser to MinIO** | Would need MinIO CORS setup, presigned-URL refresh dance every hour, and gives the browser direct S3 access we've deliberately avoided elsewhere in the app. Marginal CPU savings on the API not worth the complexity. |
| **Self-host Nominatim** | Requires a full PostGIS instance with the Indonesia OSM planet extract (~15 GB). Ops cost is out of proportion for the current usage volume (dozens of geocode calls per admin session). |

## Rollout plan

1. **Phase 1 (this PR)** — Backend maps module + frontend migration
   + CSP tightening + ops runbook. Ships DISABLED by default
   (`MAPS_ENABLED=false`) — server returns 503 for `/maps/*` so
   deployments without a seeded bucket don't render broken maps.
2. **Phase 2 (ops flip)** — Ops seeds `workpulse-maptiles` per the
   runbook, flips `MAPS_ENABLED=true`. Zero code change.
3. **Phase 3 (optional)** — Add a health check that verifies the
   PMTiles archive is present + readable, exposed at `/maps/health`
   so uptime dashboards can alert on missing bucket state.

## Followups (out of scope for this ADR)

- Cache invalidation hook for when ops uploads a new PMTiles archive
  (currently: `max-age=1w` means old tiles stale over one week; ops
  can force-refresh by bumping a `?v=` on the style URL).
- Polygon geofence support (currently: single point + radius; MapLibre
  handles polygons natively, so this becomes cheaper once we're on
  it).
- Paid geocoder fallback (Mapbox / Google) behind `MAPS_GEOCODE_FALLBACK`
  env flag for tenants with heavier geocode volume.
- Cluster / heatmap support for HR analytics ("where are our
  supervisors' teams distributed geographically?") — MapLibre has
  built-in `cluster: true` on GeoJSON sources.
